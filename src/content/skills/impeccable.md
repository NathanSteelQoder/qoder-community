## Use Cases

- Polish AI-generated frontend interfaces to production quality
- Audit existing UI designs for common issues
- Distill complex layouts into cleaner versions
- Make bolder design decisions with guided commands
- Communicate design intent precisely to AI agents

## Core Capabilities

- **17 Design Commands**: Specialized commands like /polish, /audit, /distill, /bolder
- **Design Vocabulary**: Proper terminology for communicating with AI
- **Anti-Pattern Detection**: Identifies and fixes generic "AI slop" aesthetics
- **Cross-Platform**: Works with Cursor, Claude Code, Gemini CLI, and more

## Example

```
/polish this landing page:
- Improve typography hierarchy
- Add subtle micro-interactions
- Fix spacing and alignment issues
- Make the hero section more distinctive
- Avoid generic AI color schemes
```

## Notes

- Designed as an upgrade to Anthropic's frontend-design skill
- Focuses on distinctive aesthetics over cookie-cutter AI styles
- Covers typography, color, layout, and motion patterns
- Compatible with all major AI code editors
