## Use Cases

- Create stunning presentations from scratch as single HTML files
- Convert PowerPoint files (.ppt/.pptx) to web format
- Enhance existing HTML presentations with animations
- Build slide decks with distinctive typography and design
- Create viewport-optimized responsive presentations

## Core Capabilities

- **Zero Dependencies**: Single HTML files with inline CSS/JS, no build tools needed
- **Show Don't Tell**: Generates visual previews for aesthetic exploration
- **Animation Rich**: High-impact motion design for key moments
- **Viewport Optimized**: Every slide fits exactly within 100vh, no scrolling

## Example

```
Create a presentation about our Q1 results:
- 10 slides with key metrics and achievements
- Use a dark theme with brand colors
- Add subtle entrance animations for data points
- Include chart visualizations for revenue growth
- Make it distinctive, avoid generic presentation styles
```

## Notes

- Outputs single HTML files — no npm or external dependencies
- Avoids generic fonts like Inter or Arial for distinctive typography
- Uses CSS variables for cohesive color themes
- Supports atmospheric backgrounds over solid colors
