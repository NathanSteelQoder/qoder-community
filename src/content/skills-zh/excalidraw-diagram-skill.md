## 使用场景

- 通过描述创建系统架构图
- 生成工作流和流程可视化
- 构建带有真实代码示例的教育图表
- 设计带有可视化布局的产品提案
- 绘制数据流和服务交互图

## 核心能力

- **可视化论证**：图表以视觉方式论证，而非简单展示信息
- **证据驱动**：技术图表包含真实代码片段和 JSON 数据
- **自动纠错**：使用 Playwright 渲染并自动验证布局问题
- **品牌定制**：集中式颜色调色板和样式配置

## 示例

```
创建一个 Excalidraw 图表：
- 包含 3 个服务的微服务架构
- 服务之间的消息队列
- 数据库连接
- 入口处的 API 网关
- 使用 references/color-palette.md 中的品牌色
```

## 注意事项

- 需要可选安装 Playwright 用于视觉验证
- 所有样式集中在 references/color-palette.md
- 支持系统架构、工作流、教育可视化和产品提案
- 自动检测文本重叠、箭头错位和间距问题
