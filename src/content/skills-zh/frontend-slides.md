## 使用场景

- 从零创建精美的单文件 HTML 演示文稿
- 将 PowerPoint 文件（.ppt/.pptx）转换为网页格式
- 为现有 HTML 演示文稿添加动画增强
- 构建具有独特字体和设计的幻灯片
- 创建视口优化的响应式演示文稿

## 核心能力

- **零依赖**：单个 HTML 文件，内联 CSS/JS，无需构建工具
- **展示优先**：生成可视预览用于美学探索
- **动画丰富**：关键时刻的高影响力动效设计
- **视口优化**：每张幻灯片完美适配 100vh，无需滚动

## 示例

```
创建一个关于 Q1 业绩的演示文稿：
- 10 张幻灯片，包含关键指标和成就
- 使用深色主题配合品牌色
- 为数据点添加微妙的入场动画
- 包含收入增长的图表可视化
- 风格独特，避免通用演示文稿样式
```

## 注意事项

- 输出单个 HTML 文件，无需 npm 或外部依赖
- 避免使用 Inter 或 Arial 等通用字体，追求独特排版
- 使用 CSS 变量实现统一的色彩主题
- 支持氛围背景而非纯色背景
