## 使用场景

- 构建生产级 AI 自动化工作流
- 具有语义版本控制和验证的网页抓取
- 依赖感知的任务编排执行图
- 框架导出支持 CrewAI 和 OpenAI Agents
- 自愈验证和故障恢复

## 核心能力

- **类型化输入输出**：带有类型约束的 Skill 定义
- **执行图**：依赖感知的任务编排
- **故障恢复**：自愈验证策略
- **框架导出**：支持 CrewAI 和 OpenAI Agents

## 示例

```
请创建一个 Apify Actor：
1. 抓取电商网站的商品列表
2. 提取价格、标题和库存状态
3. 输出结构化 JSON 数据
4. 自动处理分页
5. 包含失败请求的重试逻辑
```

## 注意事项

- 支持单个仓库内多个 Skill 定义
- Skills 包含语义版本控制
- 内置可选的网页抓取能力
- 请参阅 Apify 文档了解 Actor 开发模式
