## 使用场景

- 总结 B 站、YouTube 等平台的视频内容
- 从播客和会议中提取关键信息
- 处理和分析本地视频和音频文件
- 从视频内容生成结构化笔记
- 自动化视频内容理解工作流

## 核心能力

- **多平台支持**：支持 B 站、YouTube、网站和播客
- **一键总结**：即时视频和音频内容摘要
- **OpenClaw 集成**：在 OpenClaw AI Agent 生态中运行
- **本地文件**：处理本地视频和音频文件

## 示例

```
请总结这个视频：
- URL: https://www.bilibili.com/video/BV1xx...
- 提取关键要点和时间戳
- 生成结构化大纲
- 识别讨论的主要话题
- 同时输出中文和英文版本
```

## 注意事项

- 属于 OpenClaw Skills 生态系统，拥有 3,500+ 可用 Skills
- 支持多语言摘要
- 可处理在线 URL 和本地文件
- 通过 OpenClaw 集成各类消息平台
